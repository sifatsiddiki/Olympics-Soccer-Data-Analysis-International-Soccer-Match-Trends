# Olympics-Soccer-Data-Analysis-International-Soccer-Match-Trends
Data analysis project exploring international soccer match results (men and women) and tracking historical trends using Python, Pandas, and data visualization.
#  International Soccer Results Data Analysis

This project explores historical data from international soccer matches for both men and women. The goal is to analyze match trends, goal-scoring patterns, and visualize insights based on the soccer datasets.

![Soccer Pitch](soccer-pitch.jpg)

##  Key Insights & Findings
- **Goal Analysis:** Compared the average goals scored per match in men's vs. women's official international tournaments.
- **Historical Trends:** Tracked how international soccer matches and team performances have evolved over the decades.
- **Tournament Insights:** Identified which tournaments (e.g., FIFA World Cup, Olympic Games) have higher goal densities.

##  Updated Repository Structure
- `notebook.ipynb`: Main Jupyter notebook containing data processing, hypothesis testing, and visualizations.
- `men_results.csv`: Comprehensive dataset of official men's international soccer matches.
- `women_results.csv`: Comprehensive dataset of official women's international soccer matches.
- `soccer-pitch.jpg`: Background asset used for data visualization and tactical alignments.

##  Tech Stack & Requirements
- **Language:** Python
- **Libraries:** Pandas, NumPy, SciPy (for hypothesis testing/t-test), Matplotlib, Seaborn
